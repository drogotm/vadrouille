# Vadrouille — On part où ?

L'app qui trouve le week-end qui met tout le monde d'accord. Un organisateur crée une
Vadrouille, invite sa bande par lien, chacun répond en privé à un questionnaire de 2 minutes,
et le moteur de décision propose 3 options (🥇 Best Match, 💸 Budget Match, 🔥 Wild Card)
sur lesquelles le groupe vote.

> 🚧 MVP en cours de construction — ce README sera complété à la fin (lancement local,
> simulateur iOS, variables d'environnement, décisions, reste à faire).

## Démarrage rapide

```bash
npm install
cp .env.example .env   # optionnel : sans Supabase, l'app tourne en mode démo
npm run ios            # simulateur iOS
```
